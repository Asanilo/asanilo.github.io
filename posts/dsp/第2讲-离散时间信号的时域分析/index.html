一、离散时间信号的时域表示
#

1. 核心概念
#

离散时间信号是时间取值离散的信号，又称"时间序列（Time Sequence）"，数学表示为：
$$\{x[n],\ n \in (-\infty, +\infty)\}$$
其中：

  • $n$ 为整数时间索引（仅取整数，如$\dots,-2,-1,0,1,2,\dots$）；
  • $x[n]$ 为第$n$时刻的样本值，可取值为实数（连续值）或复数（回答PPT问题：离散信号样本可取实连续值）。

2. 离散信号的来源
#

离散序列通常由对连续时间信号均匀采样生成，采样过程公式：
$$x[n] = \left.x_a(t)\right|_{t=nT} = x_a(nT),\quad n=\dots,-2,-1,0,1,2,\dots$$

  • $x\_a(t)$：原始连续时间信号；
  • $T$：采样周期（单位：s/ms），采样率（频率）$f\_s = 1/T$（单位：Hz）；
  • $nT$：第$n$个采样点的时间坐标。

3. 实序列与复序列
#

类型 定义与表示 示例
实序列 样本值为实数，直接用数值序列表示 $\\{x[n]\\} = \\{\dots,2.3,3.5,4.7,\dots\\}$ 或 $\\{\dots,3,7,2,\dots\\}$
复序列 样本值为复数，分解为实部和虚部：$\\{x[n]\\} = \\{x\_{\text{re}}[n]\\} + j\\{x\_{\text{im}}[n]\\}$ $\\{x[n]\\} = \\{\dots,1+j2,j3,5+j4,\dots\\}$

4. 离散信号的强度（Lp范数）
#

信号强度由Lp范数量化，描述信号的"大小"或"能量分布"，定义：
$$\|x\|_p = \left( \sum_{n=-\infty}^{\infty} |x[n]|^p \right)^{1/p}$$

常见范数及含义：

范数类型 公式 物理意义
$L\_1$范数 $\|x\|\_1 = \sum\_{n=-\infty}^{\infty}x[n]$ 信号的"平均绝对值"，反映信号的整体幅值累积
$L\_2$范数 $\|x\|\_2 = \sqrt{ \sum\_{n=-\infty}^{\infty}x[n]^2 }$ 信号的"均方根"，与信号能量直接相关（能量$E = \|x\|\_2^2$）
$L\_{\infty}$范数 $\|x\|\_{\infty} =x[n]\_{\text{max}}$ 信号的"峰值绝对值"，反映信号的最大幅值

MATLAB计算函数：norm(x)（默认$L\_2$范数）、norm(x,1)（$L\_1$范数）、norm(x,inf)（$L\_{\infty}$范数）。

二、离散时间信号的运算
#

1. 基本时域运算
#

每种运算均需明确"定义、公式、物理意义/应用"，具体如下表：

运算类型 定义 数学公式 物理意义/应用场景
相乘 两信号对应时刻样本值相乘 $w[n] = x[n] \cdot y[n]$ 调制（如低频信号加载到载波）、加窗（截取信号片段）
相加 两信号对应时刻样本值相加 $w[n] = x[n] + y[n]$ 混音（如多声道音频叠加）、集合平均（降噪）
数乘 信号所有样本值乘以常数$A$ $w[n] = A \cdot x[n]$ 音量调节（$A>1$放大，$0
时移 信号沿时间轴平移$N$步（$N>0$右移，$N<0$左移） $w[n] = x[n - N]$ 模拟回声（声音延迟反射）、信号同步
时反 信号时间索引取反（沿$n=0$折叠） $w[n] = x[-n]$ 信号反转（如镜像处理）
触点 从单个信号引出多个相同副本 - 信号分路（如一路信号同时输入多个系统）

示例解释：若$x[n]$为音频信号，数乘对应音量旋钮（$A$越大音量越大），相加对应多人同时说话的混音，时移对应山谷中声音的回声（延迟后听到重复声音）。

2. 运算组合：线性组合与时域递归
#

  • 线性组合：多个时移信号的加权和，如：
    $$y[n] = \alpha_1 x[n] + \alpha_2 x[n-1] + \alpha_3 x[n-2] + \alpha_4 x[n-3]$$
    应用：FIR滤波器的时域实现（无反馈）。

  • 递归组合：含"输入信号时移"和"输出信号时移"的组合，如：
    $$y[n] = b_0 x[n] + b_1 x[n-1] + b_2 x[n-2] + a_1 y[n-1] + a_2 y[n-2]$$
    应用：IIR滤波器的时域实现（含反馈，利用历史输出优化当前输出）。

3. 采样率转换
#

将原序列的采样率$F\_T$转换为新采样率$F\_T'$，核心参数为转换比$R = F\_T'/F\_T$，分为两类操作：

转换类型 定义（$R$范围） 数学公式 长度变化 应用场景
上采样（插值） $R>1$（如$R=3$） $x\_u[n] = \begin{cases} x[n/L] & n=0,\pm L,\pm 2L,\dots \\\ 0 & \text{otherwise} \end{cases}$（$L=R$） 新序列长度 = $L \times$ 原长度 图像放大（Zooming）、音频升采样
下采样（抽取） $R<1$（如$R=1/3$） $y[n] = x[nM]$（$M=1/R$） 新序列长度 = 原长度 $/ M$（需整除） 图像缩小（Shrinking）、音频降采样

关键说明：

  • 上采样会在原样本间插入零点，需后续滤波（插值滤波）恢复连续信号特征；
  • 下采样前需先滤波（抗混叠滤波），避免高频成分混叠到低频。

4. 卷积运算
#

  • 定义：离散信号的卷积用于描述"线性时不变系统（LTI）的输入输出关系"，公式：
    $$y[n] = x[n] * h[n] = \sum_{k=-\infty}^{\infty} x[k] h[n - k]$$
    其中$x[n]$为输入信号，$h[n]$为系统单位脉冲响应，$y[n]$为输出信号。

  • 物理意义：创造"空间混响"——如"干"语音信号$x[n]$与小房间的单位脉冲响应（IR）$h[n]$卷积后，可模拟声音在该房间内的反射效果，让声音"带有空间感"。

  • Q&A：如何获得空间的IR？通过向空间发射短暂脉冲（如拍手声），记录反射后的信号，即为该空间的单位脉冲响应$h[n]$。

三、离散时间信号的分类
#

按不同维度可将离散信号分为多类，核心分类及标准如下：

1. 按时间长度分类
#

类型 定义 示例
有限长序列 仅在有限时间区间$N\_1 \leq n \leq N\_2$内有非零值，其余时刻为0 一段10秒的音频信号（$n=0$到$n=Fs \times 10$，$Fs$为采样率）
无限长序列 在$n \in (-\infty, +\infty)$内均可能有非零值 正弦序列$x[n] = \cos(\omega\_0 n)$

2. 按对称性分类
#

（1）实序列的对称性
#

任意实序列可分解为偶序列（偶对称）和奇序列（奇对称）之和：

  • 偶序列：$x\_{\text{ev}}[n] = x\_{\text{ev}}[-n]$，公式：$x\_{\text{ev}}[n] = \frac{1}{2}(x[n] + x[-n])$
  • 奇序列：$x\_{\text{od}}[n] = -x\_{\text{od}}[-n]$，公式：$x\_{\text{od}}[n] = \frac{1}{2}(x[n] - x[-n])$
  • 分解关系：$x[n] = x\_{\text{ev}}[n] + x\_{\text{od}}[n]$

（2）复序列的对称性
#

任意复序列可分解为共轭对称序列和共轭反对称序列之和：

  • 共轭对称序列：$x\_{\text{cs}}[n] = x\_{\text{cs}}^*[-n]$（$*$表示共轭），公式：$x\_{\text{cs}}[n] = \frac{1}{2}(x[n] + x^*[-n])$
  • 共轭反对称序列：$x\_{\text{ca}}[n] = -x\_{\text{ca}}^*[-n]$，公式：$x\_{\text{ca}}[n] = \frac{1}{2}(x[n] - x^*[-n])$
  • 分解关系：$x[n] = x\_{\text{cs}}[n] + x\_{\text{ca}}[n]$

示例：对有限长复序列$\\{g[n]\\} = \\{0,1+j4,-2+j3,4-j2,-5-j6,-j2,3\\}$（$-3 \leq n \leq 3$），可通过上述公式计算其共轭对称/反对称部分（需注意时间区间的对称性扩展）。

3. 按周期性分类
#

类型 定义 示例
周期序列 存在正整数$N$（周期），满足$\tilde{x}[n] = \tilde{x}[n + N]$对所有$n$成立 正弦序列$x[n] = 3\sin(\frac{\pi}{8}n)$（周期$N=16$）
非周期序列 不存在上述周期$N$ 指数衰减序列$x[n] = 0.2(1.2)^n \cdot \mu[n]$（$\mu[n]$为单位阶跃序列）

4. 按能量/功率分类
#

通过"总能量"和"平均功率"区分，核心公式：

  • 总能量：$\varepsilon\_x = \sum\_{n=-\infty}^{\infty} |x[n]|^2$
  • 平均功率：$P\_x = \lim\_{K \to \infty} \frac{1}{2K+1} \sum\_{n=-K}^{K} |x[n]|^2$
类型 定义 示例
能量信号 总能量有限（$\varepsilon\_x < \infty$），平均功率$P\_x = 0$ 单个脉冲信号$x[n] = \delta[n] - \delta[n-1]$
功率信号 总能量无限（$\varepsilon\_x \to \infty$），平均功率有限（$P\_x < \infty$） 周期正弦序列$x[n] = \cos(\omega\_0 n)$

5. 按可和性分类
#

类型 定义 应用场景
绝对可和序列 $\sum\_{n=-\infty}^{\infty}x[n]\leq \infty$ LTI系统的稳定性判断（绝对可和的单位脉冲响应对应稳定系统）
平方可和序列 $\sum\_{n=-\infty}^{\infty}x[n]^2 \leq \infty$ 信号能量有限的等价条件（能量信号）

Q&A：《信号与系统》中何处用到可和性？——判断LTI系统的稳定性（绝对可和）和能量守恒（平方可和）。

6. 按因果性分类
#

类型 定义 示例
因果序列 满足$x[n] = 0$对所有$n < 0$成立（仅在$n \geq 0$时有非零值） 单位阶跃序列$\mu[n]$（$n \geq 0$时为1，$n<0$时为0）
非因果序列 不满足上述条件（$n < 0$时有非零值） 序列$x[n] = \mu[n + 2]$（$n \geq -2$时为1）

四、典型离散时间序列及其性质
#

以下为DSP中最常用的典型序列，需掌握"定义、公式、性质、应用"：

1. 单位采样序列（$\delta[n]$）
#

  • 别名：单位冲击序列、单位脉冲序列。
  • 定义：仅在$n=0$时为1，其余时刻为0：
    $$\delta[n] = \begin{cases} 1 & n=0 \\ 0 & n \neq 0 \end{cases}$$
  • 时移形式：$\delta[n - k]$（仅在$n=k$时为1，其余时刻为0）：
    $$\delta[n - k] = \begin{cases} 1 & n=k \\ 0 & n \neq k \end{cases}$$
  • 核心性质：筛选性质——任意序列$x[n]$可表示为单位采样序列的加权和：
    $$x[n] = \sum_{k=-\infty}^{\infty} x[k] \delta[n - k]$$
  • 应用：构建任意离散信号、表示LTI系统的单位脉冲响应。

2. 单位阶跃序列（$\mu[n]$）
#

  • 定义：$n \geq 0$时为1，$n < 0$时为0：
    $$\mu[n] = \begin{cases} 1 & n \geq 0 \\ 0 & n < 0 \end{cases}$$
  • 时移形式：$\mu[n - k]$（$n \geq k$时为1，$n < k$时为0）。
  • 与$\delta[n]$的关系：
    • 积分关系：$\mu[n] = \sum\_{k=-\infty}^{n} \delta[k]$（阶跃是采样序列的累积）；
    • 微分关系：$\delta[n] = \mu[n] - \mu[n - 1]$（采样是阶跃的差分）。
  • 应用：表示"信号的起始时刻"（如截取$n \geq 0$的信号片段：$x[n] \cdot \mu[n]$）。

3. 正弦序列
#

  • 定义：具有周期性的振荡序列，公式：
    $$x[n] = A \cos(\omega_0 n + \phi)$$
  • 参数含义：
    • $A$：振幅（信号的最大幅值）；
    • $\omega\_0$：角频率（单位：rad/sample，反映振荡快慢，$\omega\_0 = 2\pi f$，$f$为频率，单位：cycle/sample）；
    • $\phi$：相位（单位：rad，反映信号的起始位置）。
  • 示例：$x[n] = 3\sin\left(\frac{\pi}{8}n\right)$——振幅$A=3$，角频率$\omega\_0=\frac{\pi}{8}$，频率$f=\frac{1}{16}$ cycle/sample，相位$\phi=-\frac{\pi}{2}$（因$\sin\theta = \cos(\theta - \frac{\pi}{2})$）。
  • 周期性：仅当$\frac{2\pi}{\omega\_0}$为有理数时，正弦序列才是周期序列，周期$N = \frac{2\pi}{\omega\_0} \cdot \frac{p}{q}$（$p,q$为互质整数）。

4. 指数序列
#

（1）实指数序列
#

  • 定义：$x[n] = A \alpha^n$（$A,\alpha$为实数，$n \in (-\infty, +\infty)$）。
  • 特性：
    • 若$|\alpha| > 1$：序列指数增长（如$\alpha=1.2$，$A=0.2$时，$x[n] = 0.2(1.2)^n$）；
    • 若$|\alpha| < 1$：序列指数衰减（如$\alpha=0.8$，$A=5$时，$x[n] = 5(0.8)^n$）；
    • 若$\alpha < 0$：序列正负交替（如$\alpha=-0.9$，$A=2$时，$x[n] = 2(-0.9)^n$）。

（2）复指数序列
#

  • 定义：$x[n] = A e^{(\alpha + j\omega\_0)n}$（$A,\alpha$为实数，$\omega\_0$为角频率）。
  • 欧拉分解：利用欧拉公式$e^{j\theta} = \cos\theta + j\sin\theta$，可分解为实部和虚部：
    $$x[n] = A e^{\alpha n} \cos(\omega_0 n) + j A e^{\alpha n} \sin(\omega_0 n)$$
  • 特性：
    • 若$\alpha = 0$：序列为"复正弦序列"（幅值恒定，如$x[n] = (0.65 + j0.5)^n \mu[n]$）；
    • 若$\alpha > 0$：幅值指数增长；若$\alpha < 0$：幅值指数衰减。

5. 矩形窗序列（$w\_R[n]$）
#

  • 别名：Box-Car序列。
  • 定义：仅在区间$N\_1 \leq n \leq N\_2$内为1，其余时刻为0：
    $$w_R[n] = \begin{cases} 0 & n < N_1 \\ 1 & N_1 \leq n \leq N_2 \\ 0 & n > N_2 \end{cases}$$
  • 简化形式：若$N\_1=0$，$N\_2=N-1$，则矩形窗可表示为$R\_N[n] = \mu[n] - \mu[n - N]$（长度为$N$）。
  • 应用：信号加窗——截取有限长信号片段（如$x[n] \cdot w\_R[n]$，仅保留$N\_1 \leq n \leq N\_2$的$x[n]$）。
  • Q&A：
    1. 上机实验中正弦信号的频谱是什么样子？——频谱不是理想的单根谱线，而是有"主瓣"和"旁瓣"的连续谱；
    2. 为什么？——加窗操作（矩形窗）会导致频谱"泄漏"，主瓣宽度与窗长成反比，旁瓣强度与窗的形状相关。

五、离散信号的相关分析
#

相关分析用于度量信号间的相似程度，分为"互相关"（两个信号）和"自相关"（一个信号的不同时刻）。

1. 互相关函数（$r\_{xy}[l]$）
#

  • 定义：描述两个信号$x[n]$和$y[n]$在不同时延$l$下的相似性，公式：
    $$r_{xy}[l] = \sum_{n=-\infty}^{\infty} x[n] y[n - l]$$
    其中$l$为"时延"（$l>0$表示$y[n]$相对于$x[n]$右移$l$步，$l<0$表示左移）。

  • 核心性质：$r\_{xy}[l] = r\_{yx}[-l]$（$x$与$y$的互相关等于$y$与$x$的互相关取反时延）。

  • 应用举例：

    • 雷达/声呐定位：发射信号$x[n]$，接收目标反射的延迟信号$y[n] = x[n - l\_0]$，通过互相关$r\_{xy}[l]$的峰值位置$l\_0$，可计算目标距离（距离 = 光速/声速 × $l\_0 \times T$，$T$为采样周期）；
    • 听歌识曲：将待识别片段$x[n]$与数据库中歌曲$y[n]$做互相关，峰值对应的$l$即为片段在歌曲中的位置。

2. 自相关函数（$r\_{xx}[l]$）
#

  • 定义：描述信号$x[n]$与自身在不同时延$l$下的相似性（互相关的特例，$y[n] = x[n]$），公式：
    $$r_{xx}[l] = \sum_{n=-\infty}^{\infty} x[n] x[n - l]$$

  • 核心性质：

    1. $r\_{xx}[0] = \sum\_{n=-\infty}^{\infty} |x[n]|^2 = \varepsilon\_x$（时延$l=0$时，自相关等于信号总能量）；
    2. $r\_{xx}[l] = r\_{xx}[-l]$（实信号的自相关为偶序列）；
    3. $|r\_{xx}[l]| \leq r\_{xx}[0]$（自相关的最大值在$l=0$处，时延越大相似性越低）。

  • 应用举例：

    • 周期检测：对受噪声干扰的周期信号$w[n] = \tilde{x}[n] + d[n]$（$\tilde{x}[n]$为周期信号，$d[n]$为噪声），自相关$r\_{ww}[l]$会保留$\tilde{x}[n]$的周期性（噪声自相关$r\_{dd}[l]$在$l \neq 0$时趋近于0），通过$r\_{ww}[l]$的峰值间隔可确定$\tilde{x}[n]$的周期；
    • 图像相似性：对同一人不同年龄的照片信号$x\_1[n]$和$x\_2[n]$，自相关$r\_{x1x2}[l]$的峰值在$l=0$时最大（同年龄照片最相似），$l$增大时峰值减小（年龄差距越大越不相似）。

3. 相关与卷积的关系
#

相关可通过"卷积"实现，核心公式：

  • 互相关：$r\_{xy}[l] = x[l] * y[-l]$（$x$与$y$的互相关等于$x$与$y$的时反序列的卷积）；
  • 自相关：$r\_{xx}[l] = x[l] * x[-l]$（$x$的自相关等于$x$与自身时反序列的卷积）。

物理意义差异：

  • 卷积：“创造效果”（如LTI系统的输入输出、空间混响）；
  • 相关：“度量相似”（如信号匹配、周期检测）。

4. 归一化相关
#

为消除信号幅值对相关结果的影响，定义"归一化相关系数"：

  • 自归一化相关：$\rho\_{xx}[l] = \frac{r\_{xx}[l]}{r\_{xx}[0]}$（取值范围$[-1,1]$，1表示完全相似，-1表示完全相反）；
  • 互归一化相关：$\rho\_{xy}[l] = \frac{r\_{xy}[l]}{\sqrt{r\_{xx}[0] r\_{yy}[0]}}$（取值范围$[-1,1]$，1表示$x[n]$与$y[n-l]$完全相似）。

5. 功率信号与周期信号的相关函数
#

（1）功率信号的相关函数
#

功率信号能量无限，需用"平均功率"定义相关：
$$r_{xy}[l] = \lim_{K \to \infty} \frac{1}{2K+1} \sum_{n=-K}^{K} x[n] y[n - l]$$
$$r_{xx}[l] = \lim_{K \to \infty} \frac{1}{2K+1} \sum_{n=-K}^{K} x[n] x[n - l]$$

（2）周期信号的相关函数
#

设周期信号$\tilde{x}[n]$和$\tilde{y}[n]$的周期为$N$，相关函数仍为同周期的周期信号，公式：
$$r_{\tilde{x}\tilde{y}}[l] = \frac{1}{N} \sum_{n=0}^{N-1} \tilde{x}[n] \tilde{y}[n - l]$$
$$r_{\tilde{x}\tilde{x}}[l] = \frac{1}{N} \sum_{n=0}^{N-1} \tilde{x}[n] \tilde{x}[n - l]$$

6. MATLAB计算相关
#

  • 互相关：R = xcorr(x, y)（输出$r\_{xy}[l]$，时延范围为$-(N-1)$到$N-1$，$N$为信号长度）；
  • 自相关：R = xcorr(x)（输出$r\_{xx}[l]$）。

六、本章小结
#

  1. 离散信号表示：实序列直接用数值表示，复序列分解为实部+虚部，强度用Lp范数量化；
  2. 核心运算：基本运算（相乘/相加/数乘/时移/时反）、采样率转换（上采样/下采样）、卷积（LTI系统响应）；
  3. 信号分类：按长度、对称性、周期性、能量功率、可和性、因果性划分，重点掌握实/复序列的对称分解、能量/功率信号判断；
  4. 典型序列：单位采样（筛选性质）、单位阶跃（与采样的关系）、正弦（参数含义）、指数（幅值变化）、矩形窗（加窗截取）；
  5. 相关分析：互相关（信号匹配）、自相关（周期检测），与卷积的关系，归一化相关系数。
