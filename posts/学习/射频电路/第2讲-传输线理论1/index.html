第2讲 传输线理论1：基础与无耗传输线特性
#

2.1 传输线概述：是什么、分哪类、用在哪
#

1. 传输线的定义
#

用以传输高频/微波信号或能量的装置，核心是"传递电磁场能量"，区别于低频电路的导线（仅传递电流）。

2. 传输线的分类
#

按"横截面场分布"分为三类，对应不同应用场景：

类型 典型例子 特点 应用场景
TEM波传输线 平行双线、同轴线、微带线 横截面上有电场（E）和磁场（H），无纵向分量 射频电路（如天线馈线）
TE/TM波传输线 矩形波导、圆波导 仅含横向E或横向H，有纵向分量 微波大功率传输（如雷达）
混合传输线 介质棒 场分布介于TEM与TE/TM之间 毫米波传输

3. 传输线理论的研究维度
#

传输线问题分"横向"和"纵向"，前者复杂但后者有通用规律：

  • 横向问题：研究横截面内E、H的分布（场结构），需解边值问题（不同传输线边界条件不同，如同轴线的圆柱边界、波导的矩形边界）。
  • 纵向问题：研究电磁波沿传输线轴向的传播特性（行波/驻波/行驻波），可用"分布参数电路模型"简化分析（核心：用电压/电流替代E/H，降低复杂度）。

4. 分布参数模型：为什么高频要"分布"？
#

低频电路用"集总参数"（电阻、电容集中在某个元件上），但高频下导线的电效应不可忽略，需将参数"沿导线分布"，模型如下：

分布参数 物理来源 作用
单位长度串联电阻$R_0$ 导体有限电导率+趋肤效应（高频电流集中在表面） 产生导体损耗
单位长度串联电感$L_0$ 导线电流产生高频磁场 储存磁场能量
单位长度并联电容$C_0$ 导体间电压产生高频电场 储存电场能量
单位长度并联电导$G_0$ 导体间介质非理想（有漏电流） 产生介质损耗

通俗理解：高频下，一段导线既是电阻、又是电感，还和相邻导线构成电容——这就是"分布参数"的本质。

2.2 传输线方程及其解：从电路到波的传播
#

1. 核心方程：电报方程（时域+频域）
#

（1）建立思路
#

取传输线上一微分段$\Delta z$，对其应用基尔霍夫电压定律（KVL） 和基尔霍夫电流定律（KCL），当$\Delta z \to 0$时，得到电压$U(z,t)$和电流$I(z,t)$的微分方程。

（2）时域电报方程
#
$$ \begin{cases} \frac{\partial U(z,t)}{\partial z} = -R_0 I(z,t) - L_0 \frac{\partial I(z,t)}{\partial t} \\ \frac{\partial I(z,t)}{\partial z} = -G_0 U(z,t) - C_0 \frac{\partial U(z,t)}{\partial t} \end{cases} $$
  • 左边：电压/电流沿轴向的变化率；
  • 右边：电阻/电导的损耗项（含$R_0$、$G_0$）+ 电感/电容的动态项（含$\partial/\partial t$）。
（3）频域电报方程（时谐信号）
#

高频信号通常是时谐的（$U(z,t) = \text{Re}[U(z)e^{j\omega t}]$，$I(z,t) = \text{Re}[I(z)e^{j\omega t}]$），代入时域方程得： $$ \begin{cases} \frac{dU(z)}{dz} = -Z_0 I(z) \\ \frac{dI(z)}{dz} = -Y_0 U(z) \end{cases} $$ 其中：

  • $Z_0 = R_0 + j\omega L_0$：单位长度串联阻抗（含损耗）；
  • $Y_0 = G_0 + j\omega C_0$：单位长度并联导纳（含损耗）。

2. 方程的通解：电压/电流是"入射波+反射波"
#

对频域电报方程二次求导，得到亥姆霍兹方程（描述波的传播）： $$ \frac{d^2 U(z)}{dz^2} - \gamma^2 U(z) = 0, \quad \frac{d^2 I(z)}{dz^2} - \gamma^2 I(z) = 0 $$ 其中$\gamma = \sqrt{Z_0 Y_0}$称为传播常数，展开为$\gamma = \alpha + j\beta$：

  • $\alpha$：衰减常数（Np/m），描述波沿传输线的衰减程度；
  • $\beta$：相位常数（rad/m），描述波沿传输线的相位变化。

方程的通解为： $$ U(z) = A_1 e^{-\gamma z} + A_2 e^{\gamma z}, \quad I(z) = \frac{1}{Z_c}(A_1 e^{-\gamma z} - A_2 e^{\gamma z}) $$ 其中：

  • $A_1 e^{-\gamma z}$：沿$+z$方向传播的入射波（从源到负载）；
  • $A_2 e^{\gamma z}$：沿$-z$方向传播的反射波（从负载到源）；
  • $Z_c = \sqrt{\frac{Z_0}{Y_0}}$：特性阻抗（核心参数，见下文）。

3. 关键参数的物理意义
#

参数 公式（无耗条件下$R_0=0,G_0=0$） 物理意义
特性阻抗$Z_c$ $Z_c = \sqrt{\frac{L_0}{C_0}}$ 入射波电压与入射波电流的比值（$Z_c = \frac{U^+}{I^+}$），仅与传输线结构/介质有关，与长度无关
衰减常数$\alpha$ $\alpha = 0$（无耗） 无耗时无衰减，有耗时$e^{-\alpha z}$描述波幅衰减
相位常数$\beta$ $\beta = \omega \sqrt{L_0 C_0}$ 每传播单位长度的相位变化，与波长关系：$\beta = \frac{2\pi}{\lambda}$
电长度$\theta$ $\theta = \beta z = \frac{2\pi z}{\lambda}$ 用相位表示的传输线长度（无量纲），比实际长度更实用

2.3 无耗传输线的特解：边界条件下的具体形式
#

通解中的$A_1$、$A_2$由边界条件确定，最常用的是"终端边界条件"（已知负载端电压$U_L$、电流$I_L$）。

1. 终端边界条件（$z=l$处，$U(l)=U_L$，$I(l)=I_L$）
#

通过坐标变换$z' = l - z$（$z'$：从负载向源端的距离，$z'=0$为负载，$z'=l$为源端），结合无耗条件$\gamma = j\beta$、欧拉公式$e^{jx} = \cos x + j\sin x$，最终得到： $$ \begin{cases} U(z') = U_L \cos(\beta z') + jZ_c I_L \sin(\beta z') \\ I(z') = I_L \cos(\beta z') + j\frac{U_L}{Z_c} \sin(\beta z') \end{cases} $$ 写成矩阵形式（方便工程计算）： $$ \begin{bmatrix} U(z') \\ I(z') \end{bmatrix} = \begin{bmatrix} \cos(\beta z') & jZ_c \sin(\beta z') \\ j\frac{1}{Z_c} \sin(\beta z') & \cos(\beta z') \end{bmatrix} \begin{bmatrix} U_L \\ I_L \end{bmatrix} $$

2. 反射系数与驻波比：描述负载失配的核心指标
#

当负载$Z_L \neq Z_c$时，入射波会在负载端反射，用"反射系数"和"驻波比"量化失配程度。

（1）负载反射系数$\Gamma_L$
#

定义：负载端反射波电压与入射波电压的比值： $$ \Gamma_L = \frac{U_L^-}{U_L^+} = \frac{Z_L - Z_c}{Z_L + Z_c} $$

  • 模$|\Gamma_L|$：反射波幅度占入射波的比例（$0 \leq |\Gamma_L| \leq 1$）；
  • 辐角$\phi_L$：反射波与入射波的相位差。

无耗传输线上任意点$z'$的反射系数：$\Gamma(z') = \Gamma_L e^{-j2\beta z'}$（模不变，相位随$z'$变化）。

（2）电压驻波比（VSWR）$\rho$
#

定义：传输线上电压最大值与最小值的比值： $$ \rho = \frac{U_{max}}{U_{min}} = \frac{1 + |\Gamma_L|}{1 - |\Gamma_L|} $$

  • 性质：$\rho \geq 1$（无反射时$\rho=1$，全反射时$\rho=\infty$）；
  • 与反射系数的关系：$|\Gamma_L| = \frac{\rho - 1}{\rho + 1}$（已知$\rho$可反求反射系数）。

2.4 无耗传输线的阻抗特性：输入阻抗
#

1. 输入阻抗的定义
#

传输线上任意点$z'$（距离负载$z'$）往负载看的阻抗，即该点电压与电流的比值： $$ Z_{in}(z') = \frac{U(z')}{I(z')} $$

2. 核心公式（代入特解推导）
#

$$ Z_{in}(z') = Z_c \cdot \frac{Z_L + jZ_c \tan(\beta z')}{Z_c + jZ_L \tan(\beta z')} $$
  • 关键变量：$Z_L$（负载阻抗）、$z'$（距离负载的长度）、$\beta z'$（电长度）。

3. 两个重要特性（高频电路设计的核心）
#

特性 条件 公式/结论 物理意义
λ/2重复性 $z' = n\lambda/2$（n为整数） $Z_{in}(n\lambda/2) = Z_L$ 每经过λ/2，输入阻抗与负载阻抗相等（相位循环2π）
λ/4倒置性 $z' = (2n+1)\lambda/4$ $Z_{in}((2n+1)\lambda/4) = \frac{Z_c^2}{Z_L}$ 每经过λ/4，输入阻抗与负载阻抗"倒置"（如感性变容性）

例：若$Z_c=50\Omega$，$Z_L=100\Omega$，则λ/4处输入阻抗$Z_{in}=50^2/100=25\Omega$（将100Ω倒置为25Ω）。

第2讲核心总结
#

  1. 高频传输线需用分布参数模型，核心参数：$R_0、L_0、C_0、G_0$；
  2. 无耗传输线的关键参数：$Z_c=\sqrt{L_0/C_0}$（特性阻抗）、$\beta=\omega\sqrt{L_0C_0}$（相位常数）；
  3. 负载失配的量化：$\Gamma_L=(Z_L-Z_c)/(Z_L+Z_c)$（反射系数）、$\rho=(1+|\Gamma_L|)/(1-|\Gamma_L|)$（驻波比）；
  4. 输入阻抗的核心特性：λ/2重复性、λ/4倒置性（高频匹配电路设计的基础）。
