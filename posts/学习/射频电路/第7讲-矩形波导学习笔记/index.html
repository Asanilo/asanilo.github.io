一、矩形波导概述 📌
#

1.1 基本定义与结构
#

  • 结构：横截面为矩形的封闭金属管，内部通常填充空气（或其他介质），属于单导体传输系统。
  • 核心区别：与同轴线、微带线（TEM波传输线）不同，单导体系统无法支撑TEM波（无静磁/静电场平衡），仅能传输 TE波（横电波，$E_z=0$） 或 TM波（横磁波，$H_z=0$）。

1.2 核心优势与应用
#

优势 具体说明 应用场景
低损耗 无内导体，仅内壁有损耗；封闭结构减少辐射 大功率微波传输（如雷达、通信基站）
高功率容量 横截面尺寸大，介质击穿阈值高 工业微波加热、高能物理设备
抗干扰与稳定性 封闭结构隔绝外界干扰，波型稳定 精密测量仪器、卫星通信

1.3 常见矩形波导元器件
#

矩形波导元器件示意图，含弯波导、耦合器、滤波器、短路器等

  • 典型元器件：波导弯头、波导-同轴线转接器、波导定向耦合器、波导滤波器、波导短路器等，均基于矩形波导的传输特性设计。

二、矩形波导的场分量 🔍
#

矩形波导的场分布需通过分离变量法求解麦克斯韦方程组，核心是先求纵向场分量（$E_z$ for TM波，$H_z$ for TE波），再通过纵向场推导横向场分量。

2.1 TM波（横磁波，$H_z=0$）
#

2.1.1 边界条件与纵向场分量
#

TM波的关键约束：导体表面切向电场为0，即

  • $E_z(0,y)=E_z(a,y)=0$（x方向，宽边$a$）
  • $E_z(x,0)=E_z(x,b)=0$（y方向，窄边$b$）

纵向电场$E_z$满足亥姆霍兹方程：
$$\frac{\partial^2 E_z}{\partial x^2} + \frac{\partial^2 E_z}{\partial y^2} + k_c^2 E_z = 0$$
其中$k_c$为截止波数（与模式相关）。

2.1.2 场分量通解
#

设$E_z(x,y)=X(x)Y(y)$，代入方程并结合边界条件，解得：

  • 纵向场：$E_z(x,y)=E_0 \sin\left(\frac{m\pi}{a}x\right)\sin\left(\frac{n\pi}{b}y\right)$（$m,n=1,2,\dots$）
  • 横向场分量（由$E_z$推导）：
    $$ \begin{cases} E_x = -\frac{\gamma}{k_c^2} \cdot \frac{m\pi}{a} E_0 \cos\left(\frac{m\pi}{a}x\right)\sin\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ E_y = -\frac{\gamma}{k_c^2} \cdot \frac{n\pi}{b} E_0 \sin\left(\frac{m\pi}{a}x\right)\cos\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ H_x = j\frac{\omega\varepsilon}{k_c^2} \cdot \frac{n\pi}{b} E_0 \sin\left(\frac{m\pi}{a}x\right)\cos\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ H_y = -j\frac{\omega\varepsilon}{k_c^2} \cdot \frac{m\pi}{a} E_0 \cos\left(\frac{m\pi}{a}x\right)\sin\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ H_z = 0 \end{cases} $$

2.1.3 TM波模式特点
#

  • 模式标记：$TM_{mn}$（$m$为x方向半驻波数，$n$为y方向半驻波数）；
  • 不存在的模式：$m=0$或$n=0$时所有场分量为0，故无$TM_{00}$、$TM_{10}$、$TM_{01}$；
  • 最低模式：$TM_{11}$（$m=n=1$，截止频率最低的TM模）。.

2.2 TE波（横电波，$E_z=0$）
#

2.2.1 边界条件与纵向场分量
#

TE波的关键约束：导体表面切向电场为0（推导横向场时体现），纵向磁场$H_z$满足：

  • $H_z$的边界条件推导后，允许$m=0$或$n=0$（但不可同时为0）。

纵向磁场$H_z$满足亥姆霍兹方程，解得：
$$H_z(x,y)=H_0 \cos\left(\frac{m\pi}{a}x\right)\cos\left(\frac{n\pi}{b}y\right)$$ （$m,n=0,1,2,\dots$，$m,n$不同时为0）

2.2.2 场分量通解
#

横向场分量（由$H_z$推导）：
$$ \begin{cases} E_x = j\frac{\omega\mu}{k_c^2} \cdot \frac{n\pi}{b} H_0 \cos\left(\frac{m\pi}{a}x\right)\sin\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ E_y = -j\frac{\omega\mu}{k_c^2} \cdot \frac{m\pi}{a} H_0 \sin\left(\frac{m\pi}{a}x\right)\cos\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ H_x = \frac{\gamma}{k_c^2} \cdot \frac{m\pi}{a} H_0 \sin\left(\frac{m\pi}{a}x\right)\cos\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ H_y = \frac{\gamma}{k_c^2} \cdot \frac{n\pi}{b} H_0 \cos\left(\frac{m\pi}{a}x\right)\sin\left(\frac{n\pi}{b}y\right) e^{j(\omega t-\gamma z)} \\ E_z = 0 \end{cases} $$

2.2.3 TE波模式特点
#

  • 模式标记：$TE_{mn}$（$m$、$n$含义同TM波）；
  • 不存在的模式：$m=n=0$时所有横向场为0，故无$TE_{00}$；
  • 最低模式：$TE_{10}$（$m=1,n=0$，截止频率最低的TE模，也是矩形波导的主模）。

2.3 TM与TE波的共性参数
#

TM波和TE波的截止波数$k_c$、截止波长$\lambda_c$、截止频率$f_c$ 公式完全相同：

  1. 截止波数：$k_{c_{mn}} = \sqrt{\left(\frac{m\pi}{a}\right)^2 + \left(\frac{n\pi}{b}\right)^2}=\pi \sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}$
  2. 截止波长：$\lambda_{c_{mn}} = \frac{2\pi}{k_c} = \frac{2}{\sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}}$
  3. 截止频率：$f_{c_{mn}} = \frac{v}{\lambda_c} = \frac{1}{2\sqrt{\mu\varepsilon}} \sqrt{\left(\frac{m}{a}\right)^2 + \left(\frac{n}{b}\right)^2}$

（$v=\frac{1}{\sqrt{\mu\varepsilon}}$为介质中的光速，空气介质中$v\approx c=3\times10^8\,\text{m/s}$）

三、矩形波导的传输特性 📊
#

3.1 核心传输特性：高通滤波
#

矩形波导具有高通滤波器特性——仅当工作波长$\lambda < \lambda_c$（或工作频率$f > f_c$）时，电磁波才能传播；否则为截止模（凋落模），场强沿传播方向指数衰减（无能量传输）。

（矩形波导截止波长分布图，标注各模式$\lambda_c$范围，如$TE_{10}$、$TE_{20}$、$TE_{01}$、$TM_{11}$等）

3.2 TE₁₀单模传输（工程常用）
#

3.2.1 为何选择TE₁₀模？
#

  • 最低主模：$TE_{10}$的截止频率最低，可实现单模传输的频带最宽；
  • 场分布简单：仅含3个非零场分量（$E_y$、$H_x$、$H_z$），便于设计和加工。

3.2.2 单模传输条件
#

需满足"仅$TE_{10}$模传播，其他高次模截止"，即：

  • 波长条件：$\lambda_{c_{TE_{20}}} < \lambda < \lambda_{c_{TE_{10}}}$
  • 频率条件：$f_{c_{TE_{10}}} < f < f_{c_{TE_{20}}}$

代入$\lambda_c$公式（$TE_{10}$：$m=1,n=0$；$TE_{20}$：$m=2,n=0$），简化得：

  • $\lambda_{c_{TE_{10}}}=2a$，$\lambda_{c_{TE_{20}}}=a$
  • 单模波长范围：$a < \lambda < 2a$
  • 单模频率范围：$\frac{c}{2a} < f < \frac{c}{a}$（空气介质）

3.2.3 波导尺寸设计原则
#

  • 宽边$a$：由$\lambda_{c_{TE_{10}}}=2a$决定，需满足$a \approx \frac{\lambda_0}{2}$（$\lambda_0$为中心工作波长）；
  • 窄边$b$：通常取$2b \approx a$（平衡功率容量与体积，$b$越大功率容量越高，但体积增大）。

四、TE₁₀模的详细分析 🌟
#

$TE_{10}$模是矩形波导的核心工作模式，需重点掌握其场分布、电流分布及物理意义。

4.1 TE₁₀模的场分量
#

代入$m=1,n=0$到TE波场公式，仅3个分量非零（$E_y$、$H_x$、$H_z$），简化后：
$$ \begin{cases} E_y = E_0 \sin\left(\frac{\pi}{a}x\right) e^{j(\omega t-\beta z)} \\ H_x = -\frac{\beta}{\omega\mu} E_0 \sin\left(\frac{\pi}{a}x\right) e^{j(\omega t-\beta z)} \\ H_z = j\frac{\pi}{\omega\mu a} E_0 \cos\left(\frac{\pi}{a}x\right) e^{j(\omega t-\beta z)} \\ E_x = E_z = H_y = 0 \end{cases} $$
其中$\beta = \sqrt{k^2 - k_c^2}$（$k=\frac{2\pi}{\lambda}$为波数，传播时$\beta$为实数）。

4.2 TE₁₀模的场分布规律
#

4.2.1 电场（$E_y$）分布
#

  • x方向：沿宽边呈正弦分布——$x=0$和$x=a$处（波导宽边内壁）$E_y=0$（边界条件），$x=\frac{a}{2}$处$E_y$最大（$E_0$）；
  • y方向：沿窄边均匀分布（与$y$无关）；
  • z方向：沿传播方向呈行波分布（相位随$z$滞后）。

4.2.2 磁场（$H_x$、$H_z$）分布
#

  • $H_x$（横向磁场）：与$E_y$同相位，沿x方向正弦分布（$x=\frac{a}{2}$处最大），沿y方向均匀；
  • $H_z$（纵向磁场）：与$E_y$相位差$\frac{\pi}{2}$，沿x方向余弦分布——$x=0$和$x=a$处最大，$x=\frac{a}{2}$处为0；
  • 磁场线为闭合曲线，环绕电场线。

4.3 TE₁₀模的内壁电流分布
#

波导内壁为理想导体，高频电流仅存在于内表面，电流密度由边界条件$J_s = \hat{n} \times \vec{H}$（$\hat{n}$为内壁法向量）决定：

  • 宽边（$y=0$和$y=b$）：电流主要为$J_{sz}$（纵向），由$H_x$产生；
  • 窄边（$x=0$和$x=a$）：电流为$J_{sy}$（横向），由$H_z$产生；
  • 电流分布与磁场分布直接相关，$x=\frac{a}{2}$处（$H_x$最大）宽边电流最密集。

工程意义
#

了解电流分布可指导波导缝隙设计：

  • 辐射缝隙：切割电流线（如宽边$x=\frac{a}{2}$处开缝），会向外辐射能量；
  • 非辐射缝隙：平行于电流线（如窄边开缝），不影响传输，可用于安装探针。

五、矩形波导的传输功率 📏
#

5.1 传输功率计算（TE₁₀模）
#

传输功率为坡印廷矢量在波导横截面上的积分，TE₁₀模的平均传输功率公式（空气介质，$\varepsilon=\varepsilon_0$）：
$$P = \frac{ab E_{br}^2}{480\pi} \sqrt{1 - \left(\frac{\lambda_0}{2a}\right)^2}$$
其中：

  • $E_{br}$：介质的击穿场强（空气$E_{br}\approx3\times10^6\,\text{V/m}$）；
  • $a,b$：波导宽边、窄边尺寸（m）；
  • $\lambda_0$：自由空间工作波长（m）。

5.2 功率容量影响因素
#

  1. 截面尺寸：$a$和$b$越大，功率容量越高（横截面越大，可承受的场强上限越高）；
  2. 工作波长：$\lambda_0$越接近$\lambda_{c_{TE_{10}}}=2a$，$\sqrt{1 - (\lambda_0/(2a))^2}$越小，功率容量越低；
  3. 介质特性：击穿场强$E_{br}$越高（如真空优于空气），功率容量越高。

关键结论
#

矩形波导的功率容量远高于同轴线、微带线，是大功率微波系统的首选传输线。

六、核心总结 📝
#

  1. 波型特性：矩形波导仅传TE/TM波，主模为$TE_{10}$，TM最低模为$TM_{11}$；
  2. 传输条件：高通滤波，$f > f_c$（或$\lambda < \lambda_c$），$TE_{10}$单模范围$a < \lambda < 2a$；
  3. TE₁₀模：场分量仅$E_y$、$H_x$、$H_z$，电场沿x正弦分布，电流分布决定缝隙辐射特性；
  4. 功率容量：与$a,b$、$E_{br}$正相关，远高于其他传输线。
