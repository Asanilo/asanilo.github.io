Smith圆图学习笔记
#

本讲比较枯燥，请务必动手对着Smith圆图操作一遍，理解每项操作对应的传输线变化。 做题时建议另外打印大张的Smith原图，而不是用课本附带的原图 若图片不清晰，请自行寻找高清图：）

1. 引言：为什么需要Smith圆图？
#

1.1 起源与核心价值
#

  • 背景：射频电路中，阻抗、反射系数、驻波比的计算涉及复杂复数运算，早期计算机不发达时，Phillip Smith于1939年发明"图解法工具"——Smith圆图。
  • 现代意义：虽计算机可精准计算，但Smith圆图能提供直观的几何概念与物理意义（如阻抗随传输线长度的变化规律、失配程度的可视化），仍是RF/MW电路分析与设计的核心工具（设计软件、测量仪器均集成）。

1.2 核心逻辑：阻抗与反射系数的图解对应
#

Smith圆图的本质是将"归一化输入阻抗"与"反射系数"两个参量，映射到同一张复平面（Γ平面，横坐标为反射系数实部$\Gamma_r$，纵坐标为虚部$\Gamma_i$）上，实现"一个点对应多个参量"（如一个点可同时读出$r$、$x$、$|\Gamma|$、$\phi$）。

2. Smith圆图的基础：反射系数与归一化阻抗
#

2.1 归一化处理（关键前提）
#

2.1.1 为什么要归一化？
#

不同传输线的特性阻抗$Z_c$不同，归一化后可统一使用一张圆图（消除$Z_c$的影响），计算后再反归一化得到实际阻抗。

2.1.2 定义与公式
#

  • 归一化阻抗：$z = \frac{Z}{Z_c} = r + jx$（$r=\frac{R}{Z_c}$为归一化电阻，$x=\frac{X}{Z_c}$为归一化电抗）；
  • 反归一化：$Z = z \cdot Z_c = (r + jx) \cdot Z_c$；
  • 反射系数与归一化阻抗的关系（核心推导）：
    由反射系数定义$\Gamma = \frac{Z - Z_c}{Z + Z_c}$，代入$Z = z \cdot Z_c$，化简得：
    $$\Gamma = \frac{z - 1}{z + 1} \quad \text{或} \quad z = \frac{1 + \Gamma}{1 - \Gamma}$$
    结论：反射系数$\Gamma$无需归一化（与$Z_c$无关），仅阻抗需归一化。

2.2 反射系数圆与相位射线（Γ平面的核心元素）
#

2.2.1 反射系数的表达式（无耗传输线）
#

无耗传输线任意点的反射系数：$\Gamma(l) = \Gamma_L \cdot e^{-j2\beta l}$，其中：

  • $\Gamma_L = |\Gamma_L| \cdot e^{j\phi_L}$（负载反射系数，模$|\Gamma_L| \leq 1$，相位$\phi_L$）；
  • $2\beta l$（相位变化，$\beta=\frac{2\pi}{\lambda}$，$l$为传输线长度）。

2.2.2 反射系数圆（$|\Gamma|=常数$）
#

在Γ平面中，$|\Gamma|=常数$的点满足圆的方程：$\Gamma_r^2 + \Gamma_i^2 = |\Gamma|^2$，即：

  • 圆心：均在Γ平面原点$(0,0)$；
  • 半径：$|\Gamma|$（不同$|\Gamma|$对应不同大小的圆，均在单位圆内，$|\Gamma|=1$时为单位圆）。

2.2.3 相位射线（$\phi=常数$）
#

反射系数相位$\phi = \arg(\Gamma) = \phi_L - 2\beta l$，$\phi=常数$的点满足射线方程：$\Gamma_i = \Gamma_r \cdot \tan\phi$，即：

  • 所有射线从Γ平面原点出发，不同$\phi$对应不同角度的射线（如$\phi=0^\circ$为右半实轴，$\phi=90^\circ$为上半虚轴）。

2.2.4 传输线长度与旋转方向的对应
#

传输线长度变化对应反射系数在"等Γ圆"上的旋转，规律如下：

移动方向 旋转方向 长度变化$\Delta l$与旋转角度$\Delta\phi$的关系 电长度（$\Delta l/\lambda$）与旋转角度
向电源端（远离负载） 顺时针 $\Delta\phi = 2\beta \cdot \Delta l = \frac{4\pi}{\lambda} \cdot \Delta l$ $\Delta l/\lambda=0.125$→$\Delta\phi=90^\circ$
向负载端（靠近负载） 逆时针 同上（角度为正） $\Delta l/\lambda=0.25$→$\Delta\phi=180^\circ$
周期 - 旋转$360^\circ$（$2\pi$）对应$\Delta l=\lambda/2$ $\Delta l/\lambda=0.5$→$\Delta\phi=360^\circ$

例：负载反射系数$\Gamma_L=0.7e^{j180^\circ}$（A点），向电源端移动$0.0625\lambda$，旋转角度$\Delta\phi=4\pi \times 0.0625=0.25\pi=45^\circ$（顺时针），新相位$\phi=180^\circ-45^\circ=135^\circ$，即$\Gamma(l)=0.7e^{j135^\circ}$（B点）。

2.3 归一化阻抗圆（Γ平面的阻抗映射）
#

通过$\Gamma = \frac{z - 1}{z + 1}$（$z=r+jx$），可推导出归一化电阻$r$和电抗$x$在Γ平面上的圆方程，即"r圆"和"x圆"。

2.3.1 r圆（归一化电阻圆，$r=常数$）
#

将$z=r+jx$代入$\Gamma = \frac{z - 1}{z + 1}$，分离实部$\Gamma_r$和虚部$\Gamma_i$，整理得r圆方程：
$$\left(\Gamma_r - \frac{r}{r + 1}\right)^2 + \Gamma_i^2 = \left(\frac{1}{r + 1}\right)^2$$
不同$r$对应的r圆参数：

归一化电阻$r$ 圆心坐标$(\Gamma_r, \Gamma_i)$ 半径$R$ 物理意义
0（短路） $(0, 0)$ 1 单位圆（与$\Gamma=1$圆重合）
0.5 $(1/3, 0)$ 2/3 较小电阻圆
1（匹配） $(1/2, 0)$ 1/2 过Γ平面原点的圆
2 $(2/3, 0)$ 1/3 较大电阻圆
∞（开路） $(1, 0)$ 0 右半实轴端点（单点）
  • 特点：所有r圆的圆心均在实轴上，且过Γ平面上的$(1,0)$点（开路点）。

2.3.2 x圆（归一化电抗圆，$x=常数$）
#

同理，整理得x圆方程：
$$\left(\Gamma_r - 1\right)^2 + \left(\Gamma_i - \frac{1}{x}\right)^2 = \left(\frac{1}{x}\right)^2$$
不同$x$对应的x圆参数（$x$可正可负，正为感性，负为容性）：

归一化电抗$x$ 圆心坐标$(\Gamma_r, \Gamma_i)$ 半径$R$ 物理意义
0（纯电阻） $(1, \pm\infty)$ ∞ 实轴（所有x=0的点构成实轴）
±0.5 $(1, \pm2)$ 2 较宽电抗圆
±1 $(1, \pm1)$ 1 中等电抗圆
±2 $(1, \pm0.5)$ 0.5 较窄电抗圆
∞（开路/短路） $(1, 0)$ 0 右半实轴端点（单点）
  • 特点：所有x圆的圆心均在直线$\Gamma_r=1$ 上，且过Γ平面上的$(1,0)$点（开路点）。

3. Smith圆图的结构与核心特点
#

3.1 Smith阻抗圆图的组成
#

将"反射系数圆（隐含，不标注）、相位射线（隐含）、r圆、x圆"叠加在Γ平面上，即构成Smith阻抗圆图，关键标注包括：

  • 外圈刻度：电长度（$l/\lambda$，顺时针为"向电源端"，逆时针为"向负载端"，范围0~0.5）；
  • r圆刻度：实轴及圆上标注$r$值（如0.1, 0.2, 0.5, 1, 2, 5…）；
  • x圆刻度：上半圆标注正$x$（感性，$x>0$），下半圆标注负$x$（容性，$x<0$）（如±0.1, ±0.2, ±0.5, ±1…）。

3.2 核心特点（“三点、三线、二面、二向、一转"口诀）
#

类别 具体内容
三点 1. 匹配点：圆图中心（$\Gamma=0$，$z=1$，$Z=Z_c$）；
2. 开路点：右半实轴端点（$\Gamma=1$，$z=\infty$，$Z=\infty$）；
3. 短路点：左半实轴端点（$\Gamma=-1$，$z=0$，$Z=0$）。
三线 1. 实轴：所有纯电阻点（$x=0$）；
2. 右半实轴：电压波腹点（$R_{max}=Z_c\rho$）；
3. 左半实轴：电压波节点（$R_{min}=Z_c/\rho$）。
二面 1. 上半圆：感性阻抗（$x>0$，电抗为感抗$X_L$）；
2. 下半圆：容性阻抗（$x<0$，电抗为容抗$X_C$）。
二向 1. 观察点向电源端移动：在等Γ圆上顺时针旋转；
2. 观察点向负载端移动：在等Γ圆上逆时针旋转。
一转 将Smith阻抗圆图旋转180°，得到Smith导纳圆图（阻抗$z$→导纳$y=1/z$，电阻$r$→电导$g$，电抗$x$→电纳$b$）。

3.3 Smith导纳圆图（补充）
#

3.3.1 导纳的归一化
#

  • 归一化导纳：$y = \frac{Y}{Y_c} = g + jb$（$Y_c=\frac{1}{Z_c}$为特性导纳，$g=\frac{G}{Y_c}$为归一化电导，$b=\frac{B}{Y_c}$为归一化电纳）；
  • 阻抗与导纳的关系：$y = \frac{1}{z}$（复共轭关系，在圆图上表现为"关于原点对称”）。

3.3.2 导纳圆图特点
#

  • 结构：与阻抗圆图完全相同，仅物理意义变化；
  • 二面：上半圆为容性电纳（$b>0$），下半圆为感性电纳（$b<0$）；
  • 用途：方便分析并联元件（如并联电容、电感），阻抗圆图更适合串联元件。

4. Smith圆图的工程应用（含典型例题）
#

Smith圆图的核心应用围绕"阻抗、反射系数、驻波比、波腹/波节点位置"的互求，以及阻抗匹配设计，以下结合PPT例题详解步骤。

4.1 应用1：由负载阻抗求输入阻抗与驻波比
#

例题5-2：已知无耗传输线$Z_c=50\Omega$，$Z_L=50+j50\Omega$，求$l=0.25\lambda$处的$Z_{in}$与$\rho$。
#

步骤1：归一化负载阻抗
$z_L = \frac{Z_L}{Z_c} = \frac{50+j50}{50} = 1 + j1$（$r=1$，$x=1$，感性）。

步骤2：在圆图上找"入图点A"

  • 找到$r=1$的圆和$x=1$的圆（上半圆，感性），交点即为A点；
  • 读取A点对应的电长度：$l_A/\lambda = 0.162$（外圈刻度）。

步骤3：沿等Γ圆旋转至目标长度

  • 目标长度$l=0.25\lambda$，向电源端移动（顺时针旋转），旋转电长度$\Delta l/\lambda = 0.25$；
  • 新电长度：$l_B/\lambda = 0.162 + 0.25 = 0.412$，对应交点B。

步骤4：读取B点的归一化输入阻抗
B点在$r=0.5$、$x=-0.5$的圆上，故$z_{in}=0.5 - j0.5$（容性）。

步骤5：反归一化求实际$Z_{in}$
$Z_{in} = z_{in} \cdot Z_c = (0.5 - j0.5) \times 50 = 25 - j25\Omega$。

步骤6：求驻波比$\rho$

  • 过B点的等Γ圆与实轴交于两点，读取右半实轴交点的$r$值（即$\rho$，因$R_{max}=Z_c\rho$→$r_{max}=\rho$）；
  • 得$\rho=2.6$。

4.2 应用2：由负载阻抗求波腹/波节点位置与反射系数
#

例题5-3：已知$Z_c=50\Omega$，$Z_L=50+j50\Omega$，求电压波腹/波节点位置及$\Gamma_L$。
#

步骤1~2：同应用1，入图点A（$z_L=1+j1$，$l_A/\lambda=0.162$）。

步骤3：找波腹点（右半实轴）与波节点（左半实轴）

  • 等Γ圆与实轴交于M（右，波腹点）和N（左，波节点）；
  • 波腹点位置：向电源端旋转至M点，电长度$\Delta l_{max}/\lambda = 0.25 - 0.162 = 0.088$→$l_{max}=0.088\lambda$；
  • 波节点位置：向电源端旋转至N点，电长度$\Delta l_{min}/\lambda = 0.5 - 0.162 = 0.338$→$l_{min}=0.338\lambda$。

步骤4：求负载反射系数$\Gamma_L$

  • 测量A点到原点的距离（即$|\Gamma_L|$）：$|\Gamma_L|=0.45$；
  • 测量A点与右半实轴的夹角（即$\phi_L$）：$\phi_L=64^\circ$；
  • 故$\Gamma_L=0.45e^{j64^\circ}$。

4.3 应用3：由驻波比与波节点位置求负载阻抗
#

例题5-4：已知$Z_c=50\Omega$，$\rho=2$，终端短路时电压最小点（终端）接负载后向负载移动$0.15\lambda$，求$Z_L$。
#

步骤1：画$\rho=2$的等Γ圆

  • 驻波比$\rho=2$→$r_{max}=\rho=2$（右半实轴）、$r_{min}=1/\rho=0.5$（左半实轴）；
  • 以原点为圆心，过$r=2$和$r=0.5$的圆即为$\rho=2$的等Γ圆。

步骤2：确定波节点位置

  • 终端短路时，波节点在终端（$l=0$）；接负载后，波节点向负载移动$0.15\lambda$→波节点位置为$l_{min}=0.15\lambda$（左半实轴N点）。

步骤3：找负载阻抗对应的点

  • 波节点（N点）向负载端旋转$0.15\lambda$（逆时针），与$\rho=2$的等Γ圆交于B点；
  • 读取B点的归一化阻抗：$z_L=1 - j0.65$（容性）。

步骤4：反归一化
$Z_L = z_L \cdot Z_c = (1 - j0.65) \times 50 = 50 - j32.5\Omega$。

4.4 应用4：阻抗匹配网络设计（λ/4变换器）
#

例题5-5：设计匹配网络，将$Z_{in}=25-j25\Omega$变换为$R_L=50\Omega$，$Z_c=50\Omega$。
#

核心思路：用"一段50Ω传输线+一段λ/4传输线"实现匹配，λ/4传输线的特性阻抗$Z_{c1}=\sqrt{R_{in} \cdot R_L}$。

步骤1：归一化输入阻抗
$z_{in} = \frac{25-j25}{50} = 0.5 - j0.5$（A点，电长度$l_A/\lambda=0.412$）。

步骤2：找50Ω传输线的目标点B

  • A点沿等Γ圆向负载端旋转（逆时针），交实轴于B点（纯电阻点）；
  • 读取B点的归一化电阻：$r_B=2.6$→实际电阻$R_{in}=r_B \cdot Z_c=2.6 \times 50=130\Omega$。

步骤3：计算50Ω传输线的长度

  • B点电长度$l_B/\lambda=0.25$（实轴中点）；
  • 长度$l = (0.412 - 0.25)\lambda = 0.162\lambda$。

步骤4：计算λ/4传输线的特性阻抗
$Z_{c1} = \sqrt{R_{in} \cdot R_L} = \sqrt{130 \times 50} \approx 80.62\Omega$。

5. 有耗传输线的Smith圆图修正
#

无耗传输线的反射系数模$|\Gamma|$不变（等Γ圆），但有耗传输线的$|\Gamma|$随长度衰减（$|\Gamma(l)|=|\Gamma_L| \cdot e^{-2\alpha l}$），修正方法：

  • 在圆图上叠加"衰减圆"（以原点为圆心，半径$e^{-2\alpha l}$，标注$\alpha l$值）；
  • 步骤：先按无耗计算反射系数的相位（旋转角度），再沿衰减圆缩小模值，得到实际$\Gamma(l)$。

6. 核心总结
#

  1. Smith圆图的本质：反射系数（Γ平面）与归一化阻抗（$z=r+jx$）的图解映射，一个点对应$r$、$x$、$|\Gamma|$、$\phi$四个参量；
  2. 关键操作步骤：归一化→找入图点→沿等Γ圆旋转（按移动方向定顺时针/逆时针）→读取归一化值→反归一化；
  3. 核心应用：输入阻抗计算、驻波比测量、波腹/波节点定位、阻抗匹配设计；
  4. 记忆口诀：“三点（匹配、开路、短路）、三线（实轴、波腹、波节）、二面（感性上、容性下）、二向（电源顺、负载逆）"。
