#

  • 刷抖音的视频
  • 智能手表测量心率
  • 腾讯线上会议的声音
  • 居民身份证、居民健康卡等各类卡片的信息

（二）数字化技术改变生活
#

  1. 生活用品数字化：百度、优酷、爱奇艺等视频平台，ATM 机、各类银行卡等金融工具
  2. 生活环境数字化：智慧校园（师生服务中心、数字图书馆）、智慧交通（实时路况、智慧停车）、智能家居、数字化医院、数字化农业、智慧城市等
  3. 生活方式数字化：
    • 购物送货：天猫、淘宝、京东、闲鱼等
    • 社交通信：钉钉、飞书、企业微信、WeLink 等
    • 线上会议：腾讯会议、Zoom、全时云会议等
    • 出行：高铁、地铁自动驾驶
    • 身份识别：人脸、虹膜、指纹识别

（三）未来科技离不开 DSP
#

  1. 实时语音大模型中的 DSP
流水线阶段 DSP 技术 目的与作用

音频前端处理 VAD（语音活动检测）、波束成形 聚焦信号：定位有效语音，增强目标方向，节省算力

特征提取 MFCCs（梅尔频率倒谱系数）、Mel-Spectrogram（梅尔频谱） 编码信息：提取对 AI 友好的、符合人耳感知的紧凑特征

语音合成 信号分解 / 合成模型 精细控制：将语音解耦为音高、音色等参数，便于模型学习和控制
语音合成 Griffin-Lim、上采样滤波 重建与保真：从不完整信息中恢复信号，或提升信号的最终质量
  1. 自动驾驶中的 DSP
流水线阶段 数字信号处理技术（DSP Technology） 目的与应用（Purpose & Application）
雷达信号处理（RADAR Signal Processing） 快速傅里叶变换（FFT） 核心感知：从雷达回波中解算出目标的距离、速度和角度。
- 距离测量（1D-FFT）：找到中频信号的频率峰值。
- 速度测量（2D-FFT）：计算多普勒频移。
- 角度测量（3D-FFT）：估计信号到达角（AoA）
雷达信号处理（RADAR Signal Processing） 数字滤波器（Digital Filters） 信号净化：滤除来自其他车辆雷达的射频干扰（RFI）；去除静止物体（如护栏）的反射，专注于移动目标（MTI）
图像信号处理（Image Signal Processing - ISP） 去马赛克（Demosaicing） 色彩重建：将图像传感器输出的单色拜耳阵列数据转换为全彩色的 RGB 图像，是所有后续视觉处理的基础
图像信号处理（Image Signal Processing - ISP） 卷积（Convolution）- 用于滤波与锐化 图像增强：
降噪（Noise Reduction）：使用高斯滤波、双边滤波等平滑图像，去除传感器噪声。
- 锐化（Sharpening）：增强图像的边缘和细节，提高视觉清晰度
图像信号处理（Image Signal Processing - ISP） 几何变换（Geometric Transformations） 失真校正：校正由广角镜头等引入的桶形或枕形畸变，还原场景的真实几何关系
音频信号处理（Audio Signal Processing） 边缘检测（Edge Detection - Sobel, Canny） 特征提取：提取图像中的轮廓和边缘信息，作为目标识别和车道线检测的底层输入
音频信号处理（Audio Signal Processing） 短时傅里叶变换（STFT） 环境声音识别：将麦克风录制的音频转换成时频谱（Spectrogram），用于识别紧急车辆（如救护车、警车）警报声的独特扫频模式
音频信号处理（Audio Signal Processing） 波束成形（Beamforming） 声源定位：利用多个麦克风阵列，确定警报声等关键声音的来源方向，为决策提供依据
  1. 其他领域 DSP 应用：VR/AR 头显、雷达 / 摄像头传感器融合、实时图像滤波与跟踪、MRI、EEG 信号去噪、医学成像等

（四）典型 DSP 应用案例
#

  1. 降噪耳机的秘密：自适应滤波
    • 核心技术：ANC（Active Noise Control，主动降噪）、LMS（Least Mean Square，最小均方）自适应算法
    • 原理：通过 Error mic（误差麦克风）采集外部噪声信号，ANC circuit（主动降噪电路）生成噪声反相信号，Speaker（扬声器）输出反相信号，由于波的干涉效应，两种反相位的声波在空中相遇时互相抵消，实现降噪目的
  2. 车轮 “倒转” 现象：采样与混叠
    • 核心原理：Nyquist 采样定理，公式为fs​>2fm​（fs​为采样频率，fm​为信号最高频率），当采样频率不满足该条件时，会出现混叠现象，导致视觉上车轮 “倒转”

三、数字信号处理概念
#

（一）DSP 的双重含义
#

缩写 全称 含义
DSP Digital Signal Processing 数字信号处理：分析处理数字信号的一门科学，将信号离散数字化表示，通过计算处理设备，用数值计算方法进行各种处理，达到提取有用信息便于应用的目的，常用处理方法有 AD/DA、滤波、检测、变换、编码、压缩、增强、估计、识别、参数提取、频谱分析等，是理论基础，为广义概念
DSP Digital Signal Processor 数字信号处理器：针对数字信号处理算法发展起来的处理器，是信号处理在硬件（或专用芯片）的实现 / 呈现

（二）DSP 的定义
#

  1. 来自 Wikipedia：数字信号处理是使用数字处理（如计算机或更专业的数字信号处理器）来执行各种信号处理操作的技术。以这种方式处理的数字信号是一系列数字，代表在时间、空间或频率等域中连续变量的样本。
  2. 来自 GPT-5：数字信号处理是将现实世界的信号表示为采样的、量化的序列，并应用数值算法对其进行分析、变换或合成，以实现增强、滤波、压缩、检测 / 估计和重建等任务的学科。核心工具包括卷积和相关（FIR/IIR 滤波）以及傅里叶方法（DFT/FFT）。
  3. 来自 Gemini-2.5-pro：数字信号处理器是一种专用微处理器，其架构设计用于高速、实时且高效地执行数字信号处理的基本数学运算。
  4. 补充说明：数字信号处理和模拟信号处理是信号处理的子领域。

（三）DSP 的优点
#

  1. 抗干扰能力强：对元件值的容限不敏感，受温度、环境等外部参数影响小
  2. 精度高：模拟系统中元器件精度达到一定程度已较困难，而数字系统 17 位字长可达到较高精度，十分常见
  3. 保密性好：容易加密
  4. 灵活性强：系统功能特性参数可通过改变程序或系数方便调整，比改变模拟系统简便得多
  5. 可实现模拟系统难达指标：如严格的线性相位、严格的频率滤波、多抽样率处理，可用于频率极低的信号等
  6. 模块性好：方便进行功能组合，便于管理维护
  7. 集成性好：便于 VLSI（超大规模集成电路）实现
  8. 便于分析处理：一旦信号转化为数字形式，其成分比模拟形式更易分离、分析和重新排列
  9. 可实现多维信号处理：存储二维图像信号或多维阵列信号，实现二维或多维的滤波及谱分析等
  10. 易于存储：可在硬盘、磁盘、光盘等不同存储介质中对信号进行无失真的存储、传输

（四）DSP 的不足
#

  1. 需要模数转换，增加系统复杂性
  2. 受采样频率的限制，处理频率范围有限
  3. 数字系统由耗电的有源器件构成，功耗大：数字信号处理系统中集成了几十万甚至更多的晶体管，而模拟信号处理系统中大量使用电阻、电容、电感等无源器件，随着系统复杂性增加，这一矛盾更加突出

（五）模拟信号的数字处理系统
#

系统流程：输入模拟信号f(t)→防混迭滤波器→A/D（模数转换）→数字处理系统→D/A（数模转换）→平滑滤波器→输出信号

四、信号的概念及分类
#

（一）信号的定义
#

信号是含有一定信息量的时间的函数，其中 “信息量” 是要处理的客观对象的数学表征，“时间” 为广义概念，可指时间、空间、多维等。

（二）信号的分类
#

  1. 按时间变量取值的连续性分
信号类型 时间特性 幅度特性
模拟信号（Analog signal） 连续 连续
离散信号（Discrete signal） 不连续 连续
数字信号（Digital signal） 离散（量化） 离散（量化）
抽样信号（Sampled-data signal） 离散 连续
量化阶梯信号（Quantized boxcar signal） 离散 离散
  1. 按信号值的取值分
    • 实信号
    • 复信号
  2. 按自变量个数分
维度 举例
一维信号 语音信号、心电信号（ECG）、脑电信号（EEG）、肌电信号（EMG）
二维信号 黑白图像
三维信号 彩色图像（三通道二维信号）、黑白视频、彩色视频（三通道三维信号）
  1. 按信号取值的确定性分
信号类型 特点 举例
确定性信号（Deterministic signal） 信号取值可预先确定 正弦信号
随机信号（Random signal） 每个样本值随机生成，无法提前预测 语音、天气、金融信号

  1. 其他分类维度及相关问题

    • 周期：需明确周期信号的定义及判断方法
    • 能量与功率：
      1. 问题 1：什么是能量信号？什么是功率信号？
      2. 问题 2：有几种方法求信号的能量（或功率）？
      3. 问题 3：给出能量信号和功率信号的示例？
    • 因果性：
      1. 问题 1：什么是因果信号？什么是非因果信号？
      2. 问题 2：给出因果信号和非因果信号的示例？
    • 信号长度：
      1. 问题：根据信号长度，信号可以分为哪几类？

（三）离散时间序列
#

  • 定义：离散时间信号是时间序列，可表示为{x\[n\],n∈(−∞,+∞)}（x\[n\]为第n个样本值，n为整数）
  • 示例：离散音频信号（如电话拨号音信号 DTMF）

五、典型信号举例
#

  1. 语音信号：如单词 “对了” 的语音波形
  2. 音叉信号：如 256Hz 音叉信号，在时间轴上呈现周期性的正弦波形变化
  3. 生理信号：
    • 心电图信号（ECG）：反映心脏的电活动，波形包含 P 波、QRS 波群、T 波等特征
    • 脑电图信号（EEG）：记录头皮上脑部的自发性生物电位
    • 肌电信号（EMG）：肌肉收缩产生的动作电位
  4. 图像信号：各类黑白、彩色图像，由像素点构成，包含空间域的亮度、色彩等信息

六、信号处理运算举例
#

（一）简单信号时域运算
#

运算类型 数学表达式 说明
加法 $x(n) = x\_{1}(n) \pm x\_{2}(n)$ 两个信号在同一时刻的样本值相加或相减
乘法 $x(n) = x\_{1}(n) \cdot x\_{2}(n)$ 可用于幅度调制等处理，如将低频信号调制到高频载波上
标乘 $x[n] = A x\_{1}[n]$ 信号的幅度按系数A缩放（A为常数）
延时 $y(n) = x\left(n - n\_{0}\right)$ 信号在时间上平移n0​个单位（n0​>0时右移，n0​<0时左移）
积分 $y(t) = \int\_{-\infty}^{t} x(\tau) d\tau$ 对连续时间信号进行积分运算，反映信号的累积效应
微分 $w(t) = \frac{d x(t)}{d t}$​ 对连续时间信号进行微分运算，反映信号的变化率

（二）滤波
#

  1. 定义：滤波是信号处理最重要的处理手段之一，通过滤波改变信号的频谱，保留所需频率成分，去除不需要的频率成分
  2. 常见滤波器类型：低通滤波器、带通滤波器、高通滤波器、陷波滤波器
  3. 示例：对包含 50Hz、110Hz、210Hz 三个频率的合成正弦信号进行滤波
    • 低通滤波器：保留 50Hz 低频信号，滤除 110Hz、210Hz 高频信号
    • 高通滤波器：保留 210Hz 高频信号，滤除 50Hz、110Hz 低频信号
    • 带通滤波器：保留 110Hz 中频信号，滤除 50Hz 低频信号和 210Hz 高频信号
  4. 应用：图像高频随机噪声去除、图像增强 ### （三）调制
  5. 目的： ▪ 在高频信道上传输低频信号，需要将低频信号调制到高频信号上去
    ▪ 便于信道复用
  6. 常用的调制方法：
    ➢ 幅度调制
    ➢ 频率调制
    ➢ 相位调制
    ➢ 脉冲幅度调制
