第3讲 传输线理论2：无耗工作状态、功率与有耗传输线
#

3.1 无耗传输线的工作状态：三种模式的对比
#

无耗传输线的工作状态由负载反射系数$|\Gamma_L|$ 决定，分为行波、驻波、行驻波三类，核心是"入射波与反射波的叠加效果"。

1. 行波状态：理想匹配（无反射）
#

（1）条件
#

负载阻抗等于特性阻抗：$Z_L = Z_c$（匹配负载）。

（2）关键参数
#
  • 反射系数：$|\Gamma_L|=0$（无反射波）；
  • 驻波比：$\rho=1$（电压/电流无最大值最小值之分）；
  • 输入阻抗：$Z_{in}(z') = Z_c$（沿传输线处处相等）。
（3）电压/电流分布
#
$$ U(z') = U^+ e^{-j\beta z'}, \quad I(z') = \frac{U^+}{Z_c} e^{-j\beta z'} $$
  • 振幅：沿传输线不变（$|U(z')|=|U^+|$，$|I(z')|=|U^+|/Z_c$）；
  • 相位：随$z'$增大（远离负载）而滞后（每传播λ/2，相位滞后2π）；
  • 瞬时值：$u(z',t) = |U^+| \cos(\omega t - \beta z' + \phi_0)$（行波沿$+z'$传播）。
（4）物理意义
#

负载吸收全部入射功率，无能量反射，是射频系统追求的理想状态（如天线馈线匹配，避免功率浪费）。

2. 驻波状态：全反射（无有功功率传输）
#

（1）条件
#

负载不吸收有功功率，入射波全反射：$|\Gamma_L|=1$，对应三种负载：

  • 短路：$Z_L=0$；
  • 开路：$Z_L=\infty$；
  • 纯电抗：$Z_L=jX_L$（感性/容性）。
（2）典型案例：短路线（$Z_L=0$）
#
  • 电压/电流分布（$z'$从短路端开始）： $$ U(z') = j2U^+ \sin(\beta z'), \quad I(z') = \frac{2U^+}{Z_c} \cos(\beta z') $$
  • 输入阻抗：$Z_{in}(z') = jZ_c \tan(\beta z')$（纯电抗，随$z'$变化）；
  • 驻波特征：
    • 电压波节（$|U|=0$）：$z'=n\lambda/2$（短路端为波节）；
    • 电流波腹（$|I|=max$）：$z'=n\lambda/2$（与电压波节重合）；
    • 波腹/波节间隔：λ/4（相邻波腹与波节距离为λ/4）。
（3）短路线的应用
#

利用其纯电抗特性，制作射频电抗元件或谐振器：

  • $z' < \lambda/4$：$Z_{in}$为感性（替代电感）；
  • $\lambda/4 < z' < \lambda/2$：$Z_{in}$为容性（替代电容）；
  • $z' = \lambda/4$：$Z_{in}=\infty$（并联谐振器）；
  • $z' = \lambda/2$：$Z_{in}=0$（串联谐振器）。
（4）开路线（$Z_L=\infty$）
#

与短路线类似，但驻波分布沿传输线偏移λ/4（电压波腹在开路端，电流波节在开路端），输入阻抗：$Z_{in}(z') = -jZ_c \cot(\beta z')$。

3. 行驻波状态：部分反射（有有功功率传输）
#

（1）条件
#

负载为任意复阻抗：$Z_L = R_L + jX_L$（$0 < |\Gamma_L| < 1$），入射波部分反射，叠加后既有行波分量（传递功率），又有驻波分量（产生起伏）。

（2）电压/电流分布
#

振幅沿传输线呈"周期性起伏"： $$ |U(z')| = |U^+| \sqrt{1 + |\Gamma_L|^2 + 2|\Gamma_L| \cos(2\beta z' - \phi_L)} $$ $$ |I(z')| = \frac{|U^+|}{Z_c} \sqrt{1 + |\Gamma_L|^2 - 2|\Gamma_L| \cos(2\beta z' - \phi_L)} $$

  • 电压波腹：$2\beta z' - \phi_L = 2n\pi$，$|U_{max}| = |U^+|(1 + |\Gamma_L|)$；
  • 电压波节：$2\beta z' - \phi_L = (2n+1)\pi$，$|U_{min}| = |U^+|(1 - |\Gamma_L|)$；
  • 驻波比：$\rho = U_{max}/U_{min} = (1 + |\Gamma_L|)/(1 - |\Gamma_L|)$（与之前定义一致）。
（3）负载类型与波腹/波节位置
#
负载类型 负载端状态 离开负载第一个极值（波腹/波节）
纯电阻$R_L > Z_c$ 电压波腹 无偏移（负载端就是波腹）
纯电阻$R_L < Z_c$ 电压波节 无偏移（负载端就是波节）
感性负载$X_L > 0$ 非极值点 第一个电压波腹
容性负载$X_L < 0$ 非极值点 第一个电压波节

三种工作状态对比表
#

状态 负载条件 $\Gamma_L$ 驻波比$\rho$ 功率传输 核心应用
行波 $Z_L = Z_c$ 0 1 全部传输 天线馈线、信号传输线
驻波 $Z_L=0/\infty/jX_L$ 1 $\infty$ 无传输（全反射） 电抗元件、谐振器
行驻波 $Z_L=R_L+jX_L$（复阻抗） $0<\Gamma_L<1$ $1<\rho<\infty$ 部分传输 失配场景（如负载不匹配）

3.2 无耗传输线的功率：计算与损耗
#

无耗传输线无能量损耗，任意点的平均输入功率等于负载吸收的功率（能量守恒）。

1. 功率计算方法
#

（1）通用公式（任意点）
#

平均功率为电压与电流的有功分量乘积： $$ P_{in} = \frac{1}{2} \text{Re}[U(z') I^*(z')] $$ 其中$I^*(z')$是$I(z')$的共轭复数。

（2）简化公式（波腹/波节处）
#

波腹/波节处阻抗为纯电阻（电压与电流同相），计算更简单：

  • 电压波腹处（$Z_{in}=Z_c \rho$）：$P_{in} = \frac{U_{max}^2}{2 Z_c \rho}$；
  • 电流波腹处（$Z_{in}=Z_c / \rho$）：$P_{in} = \frac{I_{max}^2 Z_c}{2 \rho}$；
  • 匹配时（$\rho=1$）：$P_{in} = \frac{U_{max}^2}{2 Z_c} = \frac{I_{max}^2 Z_c}{2}$（最简洁）。

2. 回波损耗（RL）：量化反射功率
#

定义：入射波功率与反射波功率的比值（dB表示）： $$ RL = -20 \log_{10} |\Gamma| \quad (\text{dB}) $$

  • 匹配时（$|\Gamma|=0$）：$RL=\infty$（无反射）；
  • 全反射时（$|\Gamma|=1$）：$RL=0$（全反射）；
  • 工程中：$RL > 10$dB（$|\Gamma| < 0.3$）视为"弱反射"，$RL > 20$dB（$|\Gamma| < 0.1$）视为"近似匹配"。

3. 源最大功率输出条件：共轭匹配
#

当信号源阻抗$Z_g = R_g + jX_g$，传输线输入阻抗$Z_{in} = R_{in} + jX_{in}$时，源输出最大功率的条件是： $$ Z_{in} = Z_g^* \quad (\text{共轭匹配}) $$ 即$R_{in} = R_g$，$X_{in} = -X_g$（输入阻抗的实部等于源电阻，虚部抵消源电抗）。

此时最大输出功率： $$ P_{max} = \frac{E_g^2}{8 R_g} $$ 其中$E_g$是信号源的开路电压。

3.3 有耗传输线：实际传输线的特性
#

无耗传输线是理想模型，实际传输线因$R_0 \neq 0$、$G_0 \neq 0$存在损耗，核心差异是"有衰减"和"特性阻抗复化"。

1. 关键参数的变化
#

（1）传播常数$\gamma$
#
$$ \gamma = \sqrt{(R_0 + j\omega L_0)(G_0 + j\omega C_0)} = \alpha + j\beta $$
  • 衰减常数$\alpha$（不再为0）：由导体衰减$\alpha_c$ 和介质衰减$\alpha_d$ 组成，$\alpha = \alpha_c + \alpha_d$；
  • 导体衰减：$\alpha_c = \frac{R_0}{2 Z_c}$（高频下$R_0$主导）；
  • 介质衰减：$\alpha_d = \frac{G_0 Z_c}{2}$（介质损耗大时$G_0$主导）；
  • 相位常数$\beta$：近似等于无耗值（$\beta \approx \omega \sqrt{L_0 C_0}$），损耗对相位影响小。
（2）特性阻抗$Z_c$
#
$$ Z_c = \sqrt{\frac{R_0 + j\omega L_0}{G_0 + j\omega C_0}} $$
  • 高频下（$\omega L_0 \gg R_0$，$\omega C_0 \gg G_0$）：$Z_c \approx \sqrt{\frac{L_0}{C_0}}$（近似为实数，与无耗值接近）；
  • 低频下：$Z_c$为复数（含损耗项）。

2. 反射系数的变化
#

有耗传输线上，反射系数的模随距离源端的距离减小（能量衰减）： $$ \Gamma(z') = \Gamma_L e^{-2\alpha z'} e^{-j2\beta z'} $$

  • 物理意义：越靠近源端，反射波衰减越严重；当传输线足够长（$\alpha z' \gg 1$），$|\Gamma(z')| \approx 0$，相当于"负载匹配"（衰减掩盖了反射）。

3. 传输线效率$\eta$
#

定义：负载吸收的功率$P_L$与源端输入功率$P_{in}$的比值： $$ \eta = \frac{P_L}{P_{in}} \times 100\% = e^{-2\alpha l} \times 100\% \quad (\text{忽略反射时}) $$

  • 影响因素：
  1. 传输线长度$l$：越长，衰减越大，效率越低；
  2. 衰减常数$\alpha$：$\alpha$越大（损耗越大），效率越低；
  3. 阻抗失配：失配会增加反射功率，进一步降低效率。

第3讲核心总结
#

  1. 无耗传输线的三种工作状态：行波（$Z_L=Z_c$）、驻波（$|\Gamma_L|=1$）、行驻波（$0<|\Gamma_L|<1$），需掌握各自的条件与特征；
  2. 功率计算：优先用波腹/波节处的纯电阻阻抗简化，回波损耗$RL=-20\log|\Gamma|$量化反射；
  3. 有耗传输线：核心是衰减常数$\alpha$（导体+介质损耗），效率$\eta$随长度和损耗增大而降低；
  4. 工程应用：行波用于信号传输，驻波用于制作电抗元件，共轭匹配用于最大化源功率输出。

整体复习指南
#

  1. 公式关联：反射系数$\Gamma$是连接"工作状态"“驻波比$\rho$““输入阻抗$Z_{in}$“的核心，需熟记$\Gamma=(Z_L-Z_c)/(Z_L+Z_c)$和$\rho=(1+|\Gamma|)/(1-|\Gamma|)$；
  2. 高频特性：λ/4倒置性和λ/2重复性是设计匹配电路（如λ/4阻抗变换器）的关键，需结合实例理解；
  3. 理想与实际：无耗模型用于理论分析，有耗模型用于工程计算，重点关注衰减对功率和反射的影响；
  4. 物理意义优先：不要死记公式，先理解"为什么会有反射"“驻波是怎么形成的"“衰减的来源”，再推导公式会更轻松。
